# rp-lorena

Plataforma privada de rol narrativo e interactivo con ambientación de Genshin Impact y mecánicas D&D.

- 🎭 **Salas Múltiples de Rol:** Historias independientes y cambio rápido entre escenas.
- 🎲 **Sistema de Dados D&D:** Acciones con tiradas en tiempo real (d20, modificadores, críticos).
- 💬 **Formato Narrativo Genshin:** Detección automática de acciones (`*acción*`) y diálogos estilizados.
- 🖼️ **Historial y Galería:** Subida de imágenes integradas en la historia.
- 🎵 **Ambiente Sonoro:** Reproductor de música ambiental de Teyvat.
